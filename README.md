# Small Projects

A collection of small programming and engineering projects built for practice, experimentation, and learning.

The projects in this repository are generally smaller experiments rather than complete applications. They are used to explore programming concepts, mathematics, algorithms, simulations, graphics, embedded systems, and other technical topics.

## Repository Structure

Each project is kept in its own directory and contains its source code and any files directly related to that project.

```text
small-projects/
├── project-1/
│   ├── ...
│   └── ...
│
├── project-2/
│   ├── ...
│   └── ...
│
└── ...
```

Each project has its own `README.md` describing what it does, how it works, and how to run or build it where applicable.

## Purpose

This repository is primarily a record of practical experimentation and learning. The projects may vary significantly in complexity, quality, and subject matter.

## Technologies

The technologies used vary between projects. They may include programming languages, libraries, development tools, and hardware platforms.

See the README inside each project for its specific requirements.
